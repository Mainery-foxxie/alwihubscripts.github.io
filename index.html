FREQUENTLY ASKED QUESTIONS

Need answers?

Quick answers for getting started with scripts on Roblox.

Is Alwi Hub keyless?

Yes. Alwi Hub is keyless, so there is no key system to get through. It is 100% free.

Does Alwi Hub cost anything?

No. Alwi Hub is free, with no fees, subscriptions, ads, or key to buy. Some executors and games have their own prices, so check before you pay anyone else.

Is the script safe to use?

Use it at your own risk. Scripts can stop working at times, for example after a Roblox or game update, so expect an occasional break until it is fixed.

How do I use a script on Roblox?

Copy a script from the library, open a Roblox game executor, paste the script, attach it to the game if required, and run it.

Find a Roblox executor
What is a Roblox executor?

A Roblox executor is third-party software used to run custom Luau code inside a Roblox game. Only download executors from sources you trust, and understand that unofficial tools may risk your account or device.

Why is my script not working?

Make sure your executor is attached correctly, the Roblox game is supported, and you are using an up-to-date script. Game updates can temporarily break scripts until they are fixed.
